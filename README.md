# 🎬 MovieFinder (MOFI)

MovieFinder is a responsive web application that allows users to discover movies, explore genres, view detailed information, and watch trailers. The project provides a clean and interactive interface for searching and browsing movies in real time.

## 🚀 Features

- 🔍 Search movies instantly
- 🎥 View movie details including rating, overview, and release date
- 🎭 Explore movies by genre
- ▶️ Watch official trailers
- 📱 Fully responsive modern UI
- ⚡ Fast and lightweight front-end implementation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome Icons
- Google Fonts

- Add user authentication
- Create a personal watchlist feature
- Add trending & recommended movies
